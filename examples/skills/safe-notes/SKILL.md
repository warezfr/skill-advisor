# Safe notes

Use this skill when the user pastes meeting notes and asks for a summary.

1. List the decisions that were made.
2. List the next steps, each with an owner and a date when the notes give one.
3. Keep the summary under 200 words.

This skill reads only the text the user provides. It runs no command and calls no network address.
